# Cobblemon服务器：从选配置到开服联机，避开版本不匹配与卡顿的完整思路

搜「Cobblemon服务器」的人，大致分两种。一种是刚被朋友安利了这个宝可梦模组，想找个现成的公共服进去玩；另一种是自己开了一个，结果朋友连不上，或者进去之后人物走一步顿一下，于是回来找答案。这两种需求指向的东西不太一样，但都会撞上同一堵墙：Cobblemon 是模组，不是插件，它的服务器和普通的 MC 服从根上就不是一套逻辑。

## 先搞明白一件事：Cobblemon 服务器不等于普通 MC 服

Minecraft 服务器的扩展方式有两种，差别很大。

插件（Bukkit、Spigot、Paper 这一系）跑在服务端，玩家客户端不用装任何东西，直接用原版启动器就能进。网上大量"一键开服"教程教的都是这一套。

模组（Cobblemon 走的就是这条路）必须通过模组加载器（Fabric 或 NeoForge）加载，它会往游戏里塞进全新的生物、方块、物品和机制。代价是：**每个想进服的玩家，客户端必须装一模一样的模组，而且版本号必须对得上**。差一个小版本，进来的那一刻就会被踢出去，报错里会列出"缺失或版本不一致的模组"。

Cobblemon 本身是免费开源项目，用的是 MPL 2.0 许可，模型刻意做成贴合 MC 原版方块画风的样子，不会像贴上去的。它和 Pixelmon 常被拿来比较：Pixelmon 闭源、历史更久、模型更精细，但资源占用也更高，老教程里动辄要 10–12GB 内存；Cobblemon 因为开源，addon 生态长得很快，内存门槛友好得多，4–8GB 就能跑起一个小团体的服。

目前官方维护的整合包是 CurseForge 上的 **Cobblemon Official Modpack**，分 Fabric 和 NeoForge 两个独立项目，主流版本对应 Minecraft 1.21.1。注意这两者是分开的两个项目，不是同一个包的两种配置——装错了就是连不上。

## 内存和 CPU 到底要多少

这一块的公开建议并不统一，因为它们假设的场景差别很大。裸模组 + 几个朋友，和官方整合包 + 一堆 addon 的公开服，需求能差一倍。把几个来源的说法放在一起看，大致是这个区间：

| 场景 | 玩家人数 | 建议内存 |
| --- | --- | --- |
| 裸模组 + Fabric API，小团体 | 2–5 人 | 4–6GB |
| 官方整合包或少量 addon | 5–10 人 | 6–8GB |
| 叠加 Mega Showdown、训练师包等 addon | 10–20 人 | 10–12GB |
| 公开服、需要预生成、备份、管理 | 20 人以上 | 12–16GB+ |

有托管商的文档直接写"至少 6GB"，也有写"4GB 起步、8GB 舒服"的。差异主要来自 addon 数量：每加一套 addon，就多一批生成池和模型，服务器实际负荷相当于往上一档。

CPU 比很多人想象中重要。宝可梦是被服务器持续 tick 的实体，而且这块的逻辑基本单线程，所以**一颗高主频的核，比一堆低频的核有用得多**。租便宜 VPS 时常见的坑就是"8 核看着很猛，单核主频 2.4GHz"，开服之后 TPS 会很难看。

硬盘用 NVMe，别用机械盘。区块生成和存档读写吃的就是这块的随机 IO。

## 两条路线：自己搭系统，还是直接买游戏云

如果你完全不想碰命令行，直接买托管商的整合包服是最省事的，选好包点安装就能开。国内用户通常会碰到另一个问题——这类托管商大多在海外，国内玩家连过去延迟不理想，而且很多不支持支付宝支付。

想在国内机房开服，一般有两条路：一是买一台普通 VPS，自己装 Java、下服务端、配环境；二是买游戏云，产品本身就按"开游戏服"设计，CPU 是高主频的，控制台自带可视化管理。

**雨云**（RainYun）是国内做这块比较久的一家，2018 年成立，做云服务器、游戏云、裸金属、对象存储、CDN 等产品，官网标注持有 ISP、IDC 等增值电信业务许可。它的游戏云分成三种形态：**游戏云 VPS**（独立 IP 或 NAT，扩展性强，可多开服务端）、**雨云自研游戏面板**（支持 CPU 升降级、一键开服、可视化管理、备份）、以及 **MCSM 面板**（对新手更友好，带 SFTP，页面里还有"免费领取"入口）。配置上三个形态共用同一套档位。

## 固定计费还是动态计费

雨云游戏云提供固定计费和动态计费两种模式，这一项对最终花多少钱的影响，可能比换 CPU 机型还大。

动态计费的逻辑是：平时只付较低的月租，服务器真正在高负载跑的时候才按时长计费，闲置或关机时不计时。官方的说法是"应对峰值期间性能需求，降低淡季闲置费用"。

判断标准其实很简单：

- 你们是每天固定时间上线，一开就是一晚上 → 选固定计费，省心，也不用担心时长用超。
- 一周只约一两次，玩两三个小时就散 → 动态计费更划算。

一个常见误解是"动态计费 = 按量付费，肯定贵"。恰恰相反，对低频使用的服主，动态计费是省钱的；只有当你几乎 24 小时挂着的时候，固定计费才占优。

## 从下单到朋友进服：具体怎么走

假设你买的是游戏云，服务端要自己装。流程比想象中短：

1. **选端。** 服务端加载器选 Fabric（纯 Cobblemon 体验，TPS 更稳），Minecraft 版本对齐你要用的 Cobblemon 版本，主流是 1.21.1。只有当你要混装 NeoForge 系模组时才选 NeoForge。
2. **放文件。** 从 CurseForge 下载 Cobblemon 官方整合包的**服务端包**（不是客户端包），解压后把内容放进服务器根目录。用裸模组的话，就是往 `mods` 文件夹上传 Cobblemon 本体 + Fabric API 两个 jar。
3. **改 EULA。** 打开 `eula.txt`，把 `eula=false` 改成 `eula=true`。这一步漏了服务端会直接拒绝启动。
4. **启动。** 第一次启动会比较慢，大型整合包要等所有模组生成完配置文件，控制台出现 `Done` 才算成功。
5. **拿地址。** 雨云游戏云默认是 NAT 共享 IP 模式，通过端口映射对外提供服务，所以给朋友的地址是"IP:端口"格式，记得把端口一起发过去。
6. **开白名单。** 服务器挂公网之前先把白名单打开，只放自己人进来。

朋友那边的准备工作同样不能省：所有人通过 CurseForge、Modrinth 或 Prism Launcher 安装**同一个整合包版本**，并且把启动器里的自动更新关掉——不然某个人半夜偷偷升了个版本，第二天就进不来了。

## 卡顿、掉线、进不去：按这个顺序排查

出问题时别急着加钱升配，先按顺序查：

**连不上，报"模组不匹配"。** 九成是版本问题：有人装了 NeoForge 版，有人手动更新了单个依赖，有人还在用原版客户端。让所有人对照服务器端的整合包版本号，一个字符一个字符地核。

**服里卡，TPS 掉到 18 以下。** 先动 `server.properties` 里的视距和模拟距离，这是性价比最高的一个开关。然后到 `config/cobblemon/main.json` 调生成上限——默认生成率是按小团体调的，人一多，每位玩家周围刷出的宝可梦叠加起来就是几百个实体在 tick。把 `max-pokemon-per-player` 之类的上限压下来，效果立竿见影。

**新区域加载慢、跑图就卡。** 用 Chunky 开服前把主城和常用区域预生成一遍。Cobblemon 的刷新是按生物群系标签走的，玩家为了蹲特定宝可梦会满世界乱跑，没有预生成的话每一步都在触发生成。

**不知道是谁在吃性能。** 加 Lithium、FerriteCore 这类优化模组（Fabric 系），再用 `/spark` 做个 profile，看是哪个模组占用 tick 时间最多。这比盲猜加内存有效得多。

**存档越来越大、保存时卡。** 宝可梦存储写在世界数据里，宝可梦捉得越多存档越大。解决方案是提高备份频率，而不是减少备份次数。

## 国内玩家关心的延迟问题

Cobblemon 本身不吃显卡，也不吃带宽，但**延迟直接决定抓宝可梦时的手感**。对战不同步、投球判定怪异，基本都能追到 TPS 和延迟上。

雨云的机房覆盖国内多地（宁波、宿迁、温州、深圳、重庆、湖北等）和海外（香港、日本东京、美国洛杉矶、德国法兰克福等）。选机房的原则就一条：**挑离主力玩家群体最近的那个**。都在国内就选大陆节点，团队里有海外朋友，香港或日本节点是折中方案。

另外两个容易被忽略的点：

- **防御。** 公开服被 DDoS 是常事。雨云游戏云自带一定规格的防护，具体防御规格和机房有关，加购独立 IP 时防御属性也会变，下单页面会写清楚。
- **独立 IP。** NAT 模式靠端口映射联机，功能上完全够用，但 IP 是共享的。如果你打算把服务器长期公开、或者需要用到全部端口，可以加购独立公网 IP。

## 几个常被问到的问题

**Cobblemon 服务器能用 Paper 端吗？**
不能。Paper、Spigot、Purpur 这一系跑不了真正的模组，Cobblemon 必须走 Fabric 或 NeoForge。这也是为什么很多"一键开服"面板不适合直接拿来开 Cobblemon 服——下单前先确认面板端支持 Fabric 加载，不支持就改用游戏云 VPS 自己装。

**先用免费的行不行？**
雨云的 MCSM 面板页面有"免费领取"入口，逻辑是靠积分兑换（做任务 + 每日签到攒积分，库存有限，会在固定时间补货），换到的是短期的免费游戏云。拿来验证流程、测试整合包能不能跑起来是够用的，正式开长期服还是得下单。

**买之前能不能先试试？**
雨云的云服务器和游戏云产品可以低价试用一天，每款产品限一次，具体试用价格在下单页面。另外官方提供七天无理由退订，可以自助操作。这两项用来验证"这台机器的单核性能够不够我的整合包"，比看任何评测都直接。

**长期用有没有折扣？**
新用户注册并绑定微信后可以领首月 5 折券，购买产品还有 10% 以上的积分返利，积分能提现或换优惠券。拉长付费周期通常也有额外折扣，具体力度以下单页面的实时显示为准，建议结账前把优惠券栏位翻一遍。

## 该选哪个档位，一句话说清楚

如果只是三五个朋友自己玩官方整合包、不打算加太多 addon，**入门级（2 核 4GB）勉强能跑，但进阶级（4 核 8GB）才是那个不用一直盯着 TPS 的选择**。多了 4GB 内存和一条更宽的上行，换来的是一晚上不用重启服务器。

如果你准备装 Mega Showdown、训练师包这类吃资源的 addon，或者打算把服开放给更多人，直接从超高端（6 核 12GB）起步更省事——省下的调试时间，比差价值钱。

不确定的话，用 👉 [雨云游戏云的配置选择页](https://www.rainyun.com/MzA2MTc2_) 对着自己的玩家人数和 addon 清单挑一档，先试一天再决定要不要长期续。开 Cobblemon 服最容易翻车的地方从来不是机器不够强，而是版本没对齐、视距没调、生成率没压——这些配置上的小动作，比多花一百块钱有用得多。
